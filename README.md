# AI Bot (GPT, Sora 2, NanoBanana)

Бот для генерации контента с интеграцией OpenAI, поддержкой видео (Sora 2) и фото (NanoBanana).

## Технологии
- **Go 1.24+**
- **GORM** (для работы с базой данных)
- **Redis Cloud** (для управления состояниями FSM)
- **Supabase** (как хостинг PostgreSQL)

## Быстрый старт

### 1. Настройка окружения
Скопируйте пример конфига и заполните его своими данными:
```bash
cp configs/env.example .env
```
Обязательные параметры:
- `TELEGRAM_BOT_TOKEN`: Токен от @BotFather.
- `DATABASE_URL`: Строка подключения к PostgreSQL (Supabase -> Database Settings -> Connection String).
- `OPENAI_API_KEY`: Ключ для доступа к моделям ИИ.

### 2. Запуск проекта
Для запуска бота выполните:
```bash
go run cmd/bot/main.go
```

## Тестирование
1. **База данных**: При первом запуске GORM автоматически создаст все необходимые таблицы (`AutoMigrate`).
2. **Команды бота**:
   - Отправьте `/start` — проверка приветствия.
   - Отправьте `/balance` — проверка отображения лимитов.
3. **Логи**: Все действия бота логируются через `slog` в консоль.

## Структура проекта
- `cmd/bot/`: Точка входа в приложение.
- `internal/models/`: Описание структур данных для БД.
- `internal/storage/`: Логика подключения и работы с базой.
- `configs/`: Шаблоны конфигурационных файлов.
